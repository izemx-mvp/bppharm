# Photo White AI Pilot

# CRÉATION D’UNE PLATEFORME IA PREMIUM POUR BPPHARM / PHOTO WHITE

Crée une application web SaaS complète, moderne, haut de gamme et très sophistiquée pour **BPPHARM / Photo White**, spécialisée dans la distribution et la commercialisation de produits dermocosmétiques.

Le projet doit représenter un véritable **centre de pilotage intelligent de l’activité**, intégrant plusieurs agents IA :

- Dashboard Direction
- Agent IA Community Manager
- Agent IA Service Client
- Agent IA de saisie et traitement des commandes
- Base de connaissances
- FAQ
- Applications connectées
- Configuration des agents
- Gestion et suivi des commandes

L’application doit être construite comme un **MVP front-end réaliste et entièrement démontrable**.

Utiliser uniquement des **mock data réalistes**, mais toutes les interfaces, boutons, menus, filtres, modales, formulaires, changements de statuts, actions CRUD et interactions doivent fonctionner visuellement.

Aucun bouton ne doit être décoratif ou inactif.

# 43. EXPÉRIENCE UTILISATEUR

L’application doit donner l’impression d’un vrai produit SaaS déjà commercialisé.

Je ne veux pas :

- de pages vides ;
- de tableaux sans données ;
- de boutons inactifs ;
- d’interface générique ;
- de gros blocs de texte ;
- de composants répétitifs ;
- d’effets trop agressifs.

Je veux :

- données réalistes ;
- transitions ;
- feedback utilisateur ;
- statuts ;
- toasts ;
- loaders ;
- modales ;
- drawers ;
- filtres ;
- charts ;
- calendriers ;
- timelines ;
- tooltips ;
- dropdowns ;
- actions rapides.

Accorder une attention particulière à :

1. Login
2. Dashboard
3. Conversations Service Client

5. Planning éditorial
6. Validation des commandes IA
